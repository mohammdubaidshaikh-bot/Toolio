Tool guides

Image Compressor

Compress JPG and PNG images in your browser and reduce file size.

  1. Choose an image
  2. Move the quality slider (70 is a good start)
  3. Click Start and download the result

Does it reduce quality? Lower quality means a smaller file. Around 70 to 80 usually looks the same to the eye. The output is always JPG.

Image Resizer

Change the width and height of an image in pixels.

  1. Choose an image
  2. Type a new width, a new height, or both
  3. Click Start and download

Is the ratio kept? If you fill only one box, the other is calculated to keep the original ratio. If you fill both, the image is stretched to that exact size.

JPG to PDF

Turn one or more images into a single PDF file.

  1. Choose one or more images
  2. Click Start
  3. Download the PDF (one page per image)

Can I add many images? Yes. Each image becomes one page, in the order your device lists the files.

PNG to JPG

Convert PNG images to JPG.

  1. Choose a PNG file
  2. Click Start
  3. Download the JPG

What happens to transparency? JPG has no transparency, so transparent areas become white.

JPG to PNG

Convert JPG images to PNG.

  1. Choose a JPG file
  2. Click Start
  3. Download the PNG

Will the PNG be bigger? Usually yes. PNG is lossless, so the file is often larger than the JPG.

Image to WebP

Convert images to WebP, a smaller web-friendly format.

  1. Choose an image
  2. Click Start
  3. Download the WebP file

Does every browser support WebP? Current major browsers support it, but some older software cannot open WebP files.

PDF Merge

Combine several PDF files into one.

  1. Choose two or more PDFs
  2. Click Start
  3. Download the merged PDF

Are my PDFs uploaded? No. Merging happens in your browser. Password-protected PDFs may fail.

Create a QR code for any link or text and download it as PNG.

  1. Type or paste a link or text
  2. Click Generate
  3. Download the QR image

Does the QR code expire? No. The code simply contains your text, so it works as long as the link inside works.

Is it really random? It uses your browser's secure random generator. Passwords are never sent anywhere.

Word Counter

  2. Read the counts below it

  1. Paste your text

  3. Copy the result

Does it work for all languages? Case only applies to scripts that have it, such as English. Urdu and Arabic text is unchanged.

Which date is used as today? Your device's current date.

Blog

How to Reduce Image Size Without Visible Quality Loss

Large photos from a phone are often 3 to 6 MB. For websites, forms and email, that is usually far more than needed.

1. Resize first. A 4000-pixel-wide photo shown at 800 pixels wastes most of its data. Use the Image Resizer to set a realistic width.

2. Then compress. JPG quality of 70 to 80 normally looks the same on screen but is much smaller. Try the Image Compressor.

3. Pick the right format. Use JPG for photos and PNG for graphics with sharp edges. WebP is often smaller still; see Image to WebP.

How to Merge PDF Files Into One

Combining PDFs is useful for applications, invoices and study notes.

Steps: open PDF Merge, select all the files you want to combine, click Start, then download the result.

The files are combined in the order your device lists them, so rename them 1, 2, 3 if the order matters. If a PDF is password protected, remove the password first. If you only have images, use JPG to PDF.
